## 핵심 요약


R19-11의 릴리스별 학습 메모다. 변경 이력과 지원 기능은 해당 릴리스의 공식 문서와 대조해야 한다.


## 적용 범위


적용 대상: Adaptive AUTOSAR / R19-11. 아래 기존 메모의 연도·기능 변경 설명은 공식 릴리스 기록 대조 전이며 확정된 변경 이력으로 인용하지 않는다.

## 개요

- 2019년 11월 릴리즈로, 자율 주행 및 커넥티드 차량을 지원하기 위한 기능 강화

## 주요 변경 사항

- 서비스 기반 아키텍처(SOA) 개선
- 보안 기능 강화, 특히 Secure Boot 및 통신 보호
- 실시간 운영 체제 지원 강화
