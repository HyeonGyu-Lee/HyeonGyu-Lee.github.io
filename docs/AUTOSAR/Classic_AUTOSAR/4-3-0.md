## 개요

- AUTOSAR 4.3의 주요 릴리즈로, 광범위한 기능 개선과 새로운 모듈 추가를 포함

## 주요 변경 사항

- 보안 및 안전 기능 대폭 강화
- AUTOSAR CP(Adaptive Platform)와의 통합 및 상호운용성 개선
- Secure Boot, 보안 통신 및 데이터 보호 기능 추가
- 차량 네트워킹 기능 확장(CAN-FD, Ethernet 등 지원)
