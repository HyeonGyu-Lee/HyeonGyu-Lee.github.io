## 개요

- AUTOSAR 4.1의 세번째 리비전으로, 기능 추가와 기존 기능의 개선을 포함

## 주요 변경 사항

- 네트워크 관리(NM) 및 진단 통신(DCM) 모듈의 기능 개선
- 메모리 및 리소스 관리 기능 강화
- RTE와 BSW 모듈의 인터페이스 개선
