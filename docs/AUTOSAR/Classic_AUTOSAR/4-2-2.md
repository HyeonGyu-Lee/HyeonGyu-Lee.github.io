## 개요

- AUTOSAR 4.2의 두번째 리비전으로, 새로운 기능 추가와 기존 기능의 안전화에 초점을 맞춤

## 주요 변경 사항

- 새로운 보안 기능 도입, 특히 암호화 및 인증 메커니즘 강화
- 진단 모니터링 기능 개선
- 통합 테스트 및 검증 도구 지원 강화
- 기능 안정성 향상을 위한 추가 기능 도입
