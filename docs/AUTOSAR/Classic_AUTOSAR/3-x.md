>  2006~2011


## 기초 아키텍처 도입

- AUTOSAR 첫번째 주요 릴리즈로, 소프트웨어 아키텍처의 기본 구조를 정의
- ECU 소프트웨어 아키텍처 표준화
- ASW(Application Software)와 BSW(Basic Software) 계층의 도입

## BASIC Software

- 다양한 서비스 모듈(Com, Dcm, Mem 등)을 포함하여 ECU 소프트웨어의 기본 기능 제공

## RTE (Runtime Environment)

- 소프트웨어 컴포넌트 간의 통신 및 인터페이스를 관리하는 중간 계층
- AUTOSAR 컴포넌트 간의 표준화된 인터페이스 제
