## 고속 sensor traffic이 switch uplink에 모이는 상황


1 Gbit/s link라도 여러 ingress의 burst가 한 egress로 모이면 queue와 loss가 생긴다. PHY 속도와 network 전체의 수용 능력을 분리해 분석해야 한다.


> single twisted pair의 1 Gbit/s point-to-point full-duplex 통신과 구현 조건을 정리한다.

### 특징


1000BASE-T1은 single twisted pair를 사용하는 1 Gbit/s Ethernet PHY다. 1000BASE-T의 four twisted pairs를 사용하는 배선 구성과 같은 배선 규칙으로 취급하지 않는다.


### 구성과 성능


PHY 역할, 링크 수립·훈련, 지원 매체 조건, MAC 인터페이스와 호스트 처리 능력을 확인한다. Link 속도가 높아도 송수신 처리·스위치 큐·애플리케이션으로 인한 병목은 남을 수 있다.


### 시스템 연결


센서·컴퓨팅 노드·스위치·게이트웨이 사이의 트래픽을 방향별로 분석한다. 포트 용량, uplink 집중, 패킷 크기와 burst를 고려한다. 특정 application이 반드시 이 PHY를 사용한다고 단정하지 않는다.


### 검증 항목

- link 수립·훈련과 재연결.
- 지속 처리량, burst·다중 스트림과 큐 손실.
- 패킷 오류·지연·지터.
- 온도·전원·배선 조건과 PHY 오류.
- 애플리케이션 병목과 네트워크 병목의 분리.

### 실습: 병목과 burst 분석


PHY·switch·호스트 NIC의 지원 속도와 link 상태를 먼저 확인한다. iperf3로 단일·병렬 stream을 비교한다.


```bash
iperf3 -c 192.168.10.2 -t 30
iperf3 -c 192.168.10.2 -P 4 -t 30
ip -s link show eth0
ethtool -S eth0
```



송신 CPU·수신 CPU·switch uplink·포트 drop을 함께 기록한다. 높은 링크 속도에도 throughput이 낮으면 호스트 처리와 큐 상태를 먼저 분리한다. 실제 서비스의 burst·최대 payload와 동시 트래픽으로 재검증한다.
